========================================================================
                      PPT MAKER (JSON TO PPT)
                 Standalone Windows Desktop Application
========================================================================

HOW TO RUN:
1. Double-click "PPT Maker 1.0.0.exe" to launch.
   - No Python installation required.
   - No Node.js required.
   - Everything is fully self-contained.

------------------------------------------------------------------------
IF WINDOWS SHOWS "Windows protected your PC":
------------------------------------------------------------------------
Since this is a custom-built app without an expensive commercial
enterprise certificate, Windows SmartScreen may show a security notice.

To run it:
1. Click "More info".
2. Click "Run anyway".

Alternatively:
- Right-click "PPT Maker 1.0.0.exe" -> Select "Properties"
- At the bottom of the "General" tab, check "Unblock"
- Click "Apply", then "OK".

------------------------------------------------------------------------
FEATURES:
------------------------------------------------------------------------
* Convert AI-extracted question JSON into 16:9 widescreen PowerPoint presentations.
* Authentic Assamese typography (Banikanta font) support.
* Beautiful LaTeX math formula rendering ($...$ and $$...$$).
* Slide carousel preview with question navigation.
